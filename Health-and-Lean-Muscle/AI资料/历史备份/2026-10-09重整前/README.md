# 健康与薄肌训练

这里是你的长期健康、训练和饮食记录空间。所有核心内容都使用通用 Markdown 文本保存，方便不同 AI 和编辑器读取。

## 从这里开始

1. 在 `个人档案与目标.md` 中填写你愿意提供的信息和目标；不确定的项目可以留空。
2. 每次训练后，在 `训练记录.md` 中复制模板，追加一次记录。
3. 在 `饮食记录.md` 中记录当天饮食，不必为了记录而追求精确数字。
4. 定期在 `阶段复盘.md` 中回顾变化、困难和下一步。

## 让其他 AI 接着工作

让 AI 打开这个文件夹，或把其中的文件提供给它，然后使用下面这段话：

> 请先阅读这个文件夹的 README.md、AGENTS.md 和所有记录文件，再帮助我维护健康与薄肌训练档案。先告诉我哪些信息已知、哪些缺失。不要编造记录，不要把建议写成我已经完成的事情；遵循 AGENTS.md 的记录规则。

`AGENTS.md` 是统一的 AI 协作说明；`CLAUDE.md` 和 `GEMINI.md` 是对应工具的入口提示。不同 AI 不一定自动读取这些入口，所以主动让它阅读是最可靠的方式。聊天中的 AI 只有在获得文件或文件访问权限后，才能读取和修改这里的内容。

## 文件索引

| 文件 | 用途 |
| --- | --- |
| `AGENTS.md` | AI 协作与记录规则 |
| `个人档案与目标.md` | 基础信息、目标、限制和偏好 |
| `训练记录.md` | 实际完成的训练和训练感受 |
| `训练计划.md` | 待执行建议、负重选择和进阶规则 |
| `饮食记录.md` | 实际饮食、饮水和相关感受 |
| `阶段复盘.md` | 趋势、目标调整和下阶段计划 |

记录属于个人信息，只向你愿意分享的工具提供。档案、实际记录与待执行计划分开保存；未填写的信息保持未知。
