# 健康与薄肌训练

你日常只需要看三个文件：

| 文件 | 做什么 |
| --- | --- |
| [01_个人信息与目标.md](01_个人信息与目标.md) | 我的目标、身体信息和训练理念 |
| [02_计划与长期记录.md](02_计划与长期记录.md) | 训练与饮食计划、长期体重 / 训练 / 饮食 / 恢复数据 |
| [03_每日记录.md](03_每日记录.md) | 每天随手记，练完补充，也可记录照片 |

每天写第三个文件，或直接把文字、照片发给 AI，然后说：

> 帮我整理今天的记录，并更新长期记录。

AI 会整理已发生的内容、保留未完成的计划，并更新长期数据。你不需要自己重复录入。

忙的时候，只写“练了什么、吃了什么、身体感觉如何”也可以，其他项目选填。
次日的酸痛或恢复情况可以后补。积累足够记录后，AI 会在你调用整理时顺便做简短阶段复盘。

AI 入口是 `AGENTS.md`，维护规则在 `AI资料`。需要让新 AI 读取整个文件夹；没有本地访问权限时提供相关文件。
照片原图可放在 `照片`；聊天照片能分析记录，但只有可保存的附件才会存成本地原图。

## Windows 与 Mac 同步

本文件夹使用 Git 同步到 GitHub 私有仓库，包含个人健康信息。首次上传状态和仓库地址以实际创建结果为准。

- 首次在 Mac 使用：登录自己的 GitHub，克隆该私有仓库，再让 AI 打开克隆得到的文件夹。
- 每次开始前：让 AI“先从 GitHub 拉取最新记录，再读取文件”。
- 每次整理后：让 AI“把本次记录提交并推送到 GitHub”。文件修改本身不代表已经上传。
- 切换电脑前先推送，另一台电脑开始前先拉取；避免两台同时修改同一天记录。
- 如果出现冲突，保留两边新增内容，核对同一天的事件，合并后再提交；不要直接覆盖或强制推送。
